## Approach

Every site is a single, dependency-free HTML file — no frameworks, no build step — built for:

- **Speed** — instant load, no render-blocking assets
- **Accessibility** — semantic landmarks, ARIA, keyboard navigation, reduced-motion support
- **Conversion** — clear hierarchy, one primary call-to-action, click-to-call on mobile
- **Brand fidelity** — each design keeps the business's existing colors and personality
